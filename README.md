# Rebond Running — Supplier Risk Screener & 3D Customs Atlas

Interactive decision-support site for **Rebond Running** (KEDGE MSc MTLCI Capstone, Group 3).

The site screens **25 anonymized suppliers (F01–F25)** on a risk matrix and a 3D customs atlas, and illustrates three mitigation rules (R1 second source, R2 safety stock, R3 framework contract).

## Live site

**https://aminedabachi-droid.github.io/rebond-running-risk-screener/**

Open the link above in a browser. The page is a single self-contained `index.html` file (no build step).

## Contents

- Supplier risk matrix (classes High / Medium / Low, quadrants Q1–Q4)
- R1 simulation for selected suppliers (F04, F10)
- 3D customs atlas
- How-to-read guide for classes, quadrants, and rules

All supplier identities in this repository are anonymized as **F01–F25**. No real supplier names are published.
